## 🔧 Prérequis Techniques

### Matériel
- IBM Power11 (S1014, S1022s, S1024, E1050)
- Carte Spyre PCIe Gen5
- Minimum 64GB RAM (recommandé: 256GB)
- IBM i 7.5 TR2 ou supérieur

### Logiciel
- IBM i Access Client Solutions
- Python 3.9+ (via PASE)
- Spyre SDK et Runtime
- Ansible pour IBM i (optionnel)

### Réseau
- Connectivité PCIe interne
- API REST pour intégration
- Support TLS/SSL pour sécurité
